## Offline dry runs (R01–R16)

Command (one registration per invocation, after the freeze; `--experiment`
takes the per-run registration directory, and `run` has no `--only` flag):

```
export TRADINGAGENTS_C3_BATCH=token_benchmarks/live_pilot_2x2/cand01_batch_16run_v3
export C3_BATCH_REL=$TRADINGAGENTS_C3_BATCH
export C3_FREEZE_TAG=c3-v3-final-freeze
export C3_PROTOCOL_NAME=CAND01_BATCH_2X2_PROTOCOL_V3.md
export C3_GENERATOR=scripts/gen_cand01_batch_16run_specs_v3.py
for R in R01_NVDA_C0 R02_NVDA_AB ... R16_XOM_AB; do
  TZ=UTC .venv/bin/python scripts/token_benchmark.py run \
    --experiment token_benchmarks/live_pilot_2x2/cand01_batch_16run_v3/specs/$R \
    --dry-run
done
```

A dry run writes nothing (no attempt directory, no telemetry). The per-run
result table is appended to `c3/FINAL_FREEZE_REPORT.md` after the freeze.

## What a paid run does now

1. `run --experiment <V3>` verifies the frozen commit/tag/tree/fingerprint.
2. `prepare_run_spec` copies the snapshot into the attempt's `memory/` directory.
3. `_preflight_gate` re-verifies the snapshot hash, the copy, and the containment.
4. `_config_for_spec` points the graph at that copy (never the developer log).
5. After the graph, `memory_state.json` proves the baseline is unchanged.
6. `effective_config.json` records the applied switches and the memory block.
7. A run with any unattributed provider usage, a changed snapshot, or a
   mis-consumed switch is `INVALID`/`FAILED` and is never a sample.
