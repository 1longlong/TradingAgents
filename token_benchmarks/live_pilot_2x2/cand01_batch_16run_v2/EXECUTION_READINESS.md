## 3. What the operator must do before a paid run

1. Read `c3/FINAL_FREEZE_REPORT.md` (generated at certification) — it names the
   final commit, the tree, the tag, the fingerprint and all 16 config hashes.
2. Confirm `FINNHUB_API_KEY` and `FRED_API_KEY` are present in the environment
   the run uses (`credential_state()` reports presence, never values).
3. Run the gate before **each** paid run:
   `python scripts/c3_preflight_gate.py --run-id R01 --spec <batch>/specs/R01_NVDA_C0/spec.json`
4. Execute in the registered order (`EXECUTION_ORDER.txt`). R01 is first.

No launch-directory discipline is required any more (A-00 is fixed in code),
but running from the repository root remains the documented practice.

## 4. Remaining limitations (external or by design)

| ID | Limitation | Why it is not a code fix |
| --- | --- | --- |
| L-2 | Finnhub news is fetched serially per day chunk | Performance property; changing the fetch strategy before the study would change what is measured |
| L-4 | Some module docstrings still describe the superseded GDELT-secondary architecture | Documentation drift; no behaviour. The executable routing is Finnhub-only and enforced by tests |
| L-6 | PIT is day-granular: a same-day 23:59 article is admitted for a same-day decision | Declared convention of the project |
| L-7 | n = 4, exploratory | Design; no significance claim will be made |
| L-8 | V1 `config_sha256` values are permanently void | The V1 generator was lost before this work began; V1 is not a numeric baseline |
| L-9 | The V1 manifest's stale R01 spec hash is historical | V1 artefacts are preserved untouched |
| L-10 | `s2_downstream` has no OFF implementation and is refused when `false` | No OFF path exists; refusing rather than inventing a no-op is the honest behaviour |
| L-11 | Global news is disabled in every arm | Design; no global-news effect is in scope. `get_insider_transactions` has no Finnhub implementation and is not bound to the three run analysts |
| — | `tests/test_cli_prefs.py` is `.env`-coupled and would fail in a full-suite run | Pre-existing at RC1 and byte-identical to it; fixing it is a separate hermeticity change, and the full suite is outside this round's scope. Recorded here rather than hidden |
